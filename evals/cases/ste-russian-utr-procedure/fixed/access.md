# Назначение прав доступа

Администратор назначает права доступа пользователю только после согласования заявки владельцем системы.
Без согласования назначать права доступа запрещено.

Чтобы назначить права доступа:
1. Откройте окно «Права доступа».
2. Выберите опцию «Доступ к системе».
3. Нажмите «ОК».

Права доступа пользователя:
- просмотр отчётов;
- выгрузка отчётов.
