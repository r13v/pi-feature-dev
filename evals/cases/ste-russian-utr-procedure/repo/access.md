# Назначение прав доступа

Назначение прав доступа пользователю осуществляется администратором только после согласования заявки владельцем системы.

Для того, чтобы назначить права доступа, необходимо:
1. Осуществить открытие окна «Права доступа».
2. Осуществить выбор опции «Доступ к системе».
3. Выполнить нажатие «ОК».

Права доступа пользователя включают в себя следующие привилегии: просмотр отчётов, выгрузка отчётов.

При отсутствии согласования назначение прав доступа запрещено.
