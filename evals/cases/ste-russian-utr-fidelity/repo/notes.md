# Ограничения

Назначить права доступа пользователю, который не имеет прав доступа.

На выполнение данной процедуры требуется 2–3 минуты. Хотя в зависимости от конфигурации может потребоваться и больше.

Права доступа могут быть назначены только администратором после согласования заявки владельцем системы.
